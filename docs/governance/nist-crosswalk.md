# NIST crosswalk

Draft for owner review (2026-11-26)

This maps each control in the [control matrix](control-matrix.md) to NIST AI RMF 1.0 subcategories and to the risks in the Generative AI Profile (NIST AI 600-1). The anchor choice is in [ADR 0016](../decisions/0016-governance-and-release-gates.md).

**All tags are suggestions for the owner to accept or change.** Use the blank "Accept?" column. I wrote the subcategory numbers from memory of AI RMF 1.0, which has GOVERN 1-6, MAP 1-5, MEASURE 1-4 and MANAGE 1-4. Check each one against the NIST text before you quote it in an interview (check against source). The AI 600-1 risk names are the twelve named in the Profile. Controls keep the status the control matrix gives them. Nothing here marks a deployment control as implemented, and nothing is deployed yet.

## Gaps

AI 600-1 risks with no control in the matrix, and thin areas of MAP. Each has a one-line proportionate response or a reason it is out of scope.

| Gap | Response |
|---|---|
| CBRN Information or Capabilities | Out of scope as a build item. The corpora are SEC 10-Ks and an FAA handbook, and the model only answers from retrieved passages. Say so in the system card. |
| Dangerous, Violent, or Hateful Content | No control today. The generator is told to answer only from sources (C2), and the corpora are benign. Proportionate response: add a handful of off-topic and harmful-request prompts to the injection set and report what happens. Otherwise accept as low risk. |
| Obscene, Degrading, and/or Abusive Content | Same as above. A user could type abusive text, but the system returns only text grounded in the sources. Accept as low risk and note it in the risk register. |
| Harmful Bias and Homogenization | Out of scope for measurement. The system adds no model of its own and answers from two fixed corpora. Note in the system card that answers inherit the bias of the source documents and of the model providers' models. |
| Environmental Impacts | Out of scope as a build item. Each question is gated at a mean of $0.005 or less (C25), so the footprint is small. One line in the system card is enough. |
| Human-AI Configuration beyond the notice | C9 (citations a reader can check) and C15 (the AI notice, planned) are the only controls. Proportionate response: [human-oversight.md](human-oversight.md) states what a person can check and override. Add a short "how to read an answer" line to the UI if the owner wants it. |
| MAP: no intended-use or out-of-scope statement | Write them in the [system card](system-card.md) skeleton (MAP 1.1, MAP 3.3). This is a short text task. |
| MAP: no impact analysis | The [risk register](risk-register.md) rates likelihood and impact, which is the nearest thing (MAP 5.1). A one-page impact note (who could be affected, how) would close it. Proportionate for a demo with no accounts and no actions. |
| MAP: no stated limits of the system | Partly in ADRs (for example the figure crops in [ADR 0006](../decisions/0006-parsing.md)). Collect them in the system card (MAP 2.2). |
| MAP: no human oversight process defined | Covered by [human-oversight.md](human-oversight.md) (MAP 3.5, check against source). |
| Information Integrity and Intellectual Property | Only lightly covered (C7, C9, C33; C18, C33). The data card covers rights ([data card, section 2](data-card.md)). No further build item suggested. |
